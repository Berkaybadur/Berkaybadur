### 👨‍💻 Hakkımda

- 🔭 **RND E-Ticaret**'te Kıdemli Yazılım Geliştirme Uzmanı olarak **.NET / C#** tabanlı sistemler geliştiriyorum (Ocak 2021 – Halen)
- 🛒 Ürün ve kategori servisleri, stok sistemleri ve e-ticaret CRM/CSM modülleri üzerinde çalışıyorum
- ⚙️ REST API, SOAP servisleri, **CQRS**, Elasticsearch, Redis, MongoDB ve Docker kullanıyorum
- 🧩 OpenAI API entegrasyonlarını .NET servisleri içinden yönetiyorum
- 🎓 İstanbul Ayvansaray Üniversitesi, Bilgisayar Programcılığı (Önlisans)
- 💬 Tasarım kalıpları, SOLID prensipleri ve backend mimarisi hakkında konuşmaktan keyif alırım
